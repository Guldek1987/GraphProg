# Result tables

Compact CSV tables preserve the saved experimental values. Prefixes identify the notebook that produced each table; the `07_*` tables provide the final common test comparison. `06_paired_effects.csv` contains the complete learner-clustered intervals, while `07_statistical_tests.csv` contains the corresponding multiplicity-adjusted tests.

The binary test tables use 22,899 first-task visits. The separate school table uses 397 observations. Ablations use seed 17 and should not be compared as though they were three-seed ensembles. Missing efficiency measurements are missing values, not zero cost.

`runtime/` and non-curated intermediate tables are generated during sequential execution and excluded from version control.
